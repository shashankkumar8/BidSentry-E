## Social-media post (publish publicly after the repository is ready)

Meet BidSentry — an evidence-first tender-readiness copilot for India's MSMEs.

Finding a tender is only step one. The hard part is checking the qualification clauses, turnover thresholds, experience, registrations, bid security and the latest amendments before investing in a bid.

BidSentry combines TinyFish Search + Fetch, a user-triggered Web Agent, a quote-verification pass that matches returned excerpts against a separate source fetch, an evidence-linked Clause Ledger, declared bid-security capacity checks and page-change checks. It shows the source behind each signal, flags potential blockers, and keeps unknown requirements visible instead of guessing.

Built as a decision-support tool: it does not guarantee eligibility or submit bids automatically.
